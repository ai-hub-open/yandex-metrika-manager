# Шаблон отчёта аудита

Шаг 7 собирает находки в `findings.json`, а `scripts/render_report.py` делает из него **самодостаточный HTML** `АУДИТ_МЕТРИКИ_<slug>.html` (без сети и пакетов; печать в PDF из браузера — Ctrl+P).

## Принципы

- Порядок: **дашборд → «Главное» (топ-5) → разделы по областям → гипотезы для A/B → «Чего не смогли проверить»**.
- Области: Паспорт, Качество данных, Цели, Разметка и источники, Директ, Поведение и воронки.
- Каждая карточка самодостаточна: диагноз с числами → что сделать → где (в Метрике/на сайте/в Директе) → как перепроверить самому → ожидаемый эффект → кто делает.
- Язык человеческий: без `ym:s:*`, `lastsign`, `dry_run`; без `≤`/`≥` — словами.
- Скилл в аудите ничего не менял — это сказано в подвале.

## Схема `findings.json`

```json
{
  "meta": {
    "slug": "acme",
    "site": "acme.ru",
    "counter_id": 12345678,
    "period": "2026-09-05..2026-10-04",
    "compared_to": "2026-08-06..2026-09-04",
    "summary": {
      "visits": 41200,
      "macro_goal": "Заявка — отправлена",
      "macro_reaches": 812,
      "macro_cr": 0.0197,
      "robots_share": 0.06,
      "data_trust": "средняя"
    },
    "limitations": ["Директ не связан со счётчиком — расходы и CPA не оценены"]
  },
  "findings": [
    {
      "id": "F1",
      "area": "Цели",
      "severity": "critical",
      "title": "Директ учится на шумной цели",
      "evidence": "Цель «Просмотр 2 страниц» достигнута в 46% визитов за 30 дней (18 950 из 41 200)",
      "threshold": "CR цели больше 30% — шумная",
      "recommendation": "Перевести стратегию Директа на цель «Заявка — отправлена» (ID 3456) или микро «Форма — открыта» (ID 3457)",
      "where": "Директ → параметры кампании → стратегия → цели",
      "owner": "маркетолог",
      "how_to_verify": "Метрика → Отчёты → Конверсии, цель «Просмотр 2 страниц»",
      "expected_effect": "Директ перестанет покупать дешёвые клики без заявок",
      "ready_to_use": null,
      "confidence": "высокая"
    }
  ],
  "hypotheses": [
    {
      "observation": "Мобильная конверсия формы 12% против 31% на десктопе",
      "hypothesis": "Сокращение формы до 3 полей поднимет мобильную конверсию",
      "metric": "CR «Заявка» у мобильных",
      "decision_rule": "Рост не меньше 15%, значимость 95%",
      "duration": "≈ 24 дня при 140 мобильных визитах в день на вариант"
    }
  ]
}
```

`severity`: `critical` 🔴 / `major` 🟠 / `minor` 🟡 / `info` ⚪.
`data_trust`: `высокая` / `средняя` / `низкая` — итоговая оценка «можно ли верить цифрам» по Шагам 1–3.

## Сборка

```
python -m scripts.render_report --input metrika/<slug>/audit/findings.json [--output путь.html]
```
