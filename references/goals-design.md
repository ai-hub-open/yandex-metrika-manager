# Дизайн целей и сегментов

Цели — ключевые шаги к ценности продукта. Грамотный набор целей формирует фокус команды и то, на чём учится Директ. События между целями показывают, где пользователь задерживается.

## Иерархия

| Уровень | Что это | Примеры | Для чего |
|---|---|---|---|
| **Макро** (1–3) | бизнес-результат на сайте | заявка отправлена, оплата, звонок (коллтрекинг), запись | KPI, CPA, стратегия Директа |
| **Микро** (3–8) | шаги к макро | открыл форму, начал заполнять, в корзину, клик по телефону/мессенджеру, просмотр цены | воронка, ранние сигналы, обучение Директа при малом числе макро |
| **Вовлечённость** (0–3) | интерес | 3+ страницы, 60+ секунд, скролл ключевого блока | сегменты, диагностика посадок; **не** для оптимизации Директа |

Составная цель (`step`, 2–5 шагов) — для воронки: шаги в порядке пути, например «Каталог → Карточка → Корзина → Оформление → Оплата».

## Какой тип выбрать

| Задача | Тип | Условие |
|---|---|---|
| Страница «спасибо» с отдельным URL | `url` | `exact` или `start` по пути `/thanks`; **не** `contain` по общему куску |
| Форма без перезагрузки, клик, SPA | `action` | JS-событие `ym(<counter>, 'reachGoal', '<id>')`, условие `exact` по id |
| Клик по телефону / email / мессенджеру | `phone` / `email` / `messenger` | автоматически, без кода |
| Скачивание файла | `file` | `all_files` или `file` с именем |
| Поиск по сайту, чат, платёжная система | `search` / `chat` / `payment_system` | автоматически |
| Глубина / время | `number` (`depth` ≥2) / `visit_duration` (`duration`, сек) | только как вовлечённость |
| Воронка | `step` | `steps` по порядку, у каждого свой `type` и `conditions` |

URL-цель при отправке формы через AJAX не сработает — нужен `action`.

## Нейминг

`[Уровень] Объект — действие`, по-русски, единообразно:
- `[Макро] Заявка — отправлена`
- `[Микро] Форма заявки — открыта`
- `[Микро] Телефон — клик`
- `[Вовл] 3+ страницы`
- выключенные: `[OFF] <старое имя>`

## Ценность

У макро-целей — `default_price` (средняя ценность лида/заказа × доля доходящих до оплаты), чтобы Метрика и Директ могли считать ценность каналов. Если ценность неизвестна — спроси человека; не выдумывай.

## Цели и Директ

- Директ оптимизируется на макро-цель. Если макро-конверсий меньше ~10 в неделю на кампанию — обучаться на ближайшую к ней микро-цель (не на вовлечённость).
- Шумная цель в стратегии = Директ покупает дешёвый мусор. Это находка 🔴.
- Изменение условия цели, на которую учится Директ, сбрасывает смысл накопленной статистики — предупреждать при `goals_update`.
- ID цели после создания — сказать человеку, где указать в Директе (стратегия / ключевые цели). Скилл в Директ не пишет.

## Сегменты

- `expression` — в синтаксисе `filters` отчётов. Перед созданием проверь размер тем же фильтром (рецепт R20).
- Полезные для ретаргетинга шаблоны (сверь поля):
  - были на ключевой странице, не оставили заявку — `ym:s:startURL=@'/price' AND ym:s:goal<MACRO>reaches==0` *(условие по метрике в сегменте может не приниматься — тогда сегмент по странице, а исключение достигших делать аудиторией в Директе)*;
  - пришли из рекламы и смотрели прайс — `ym:s:lastsignTrafficSource=='ad' AND ym:s:startURL=@'/price'`;
  - мобильные из региона — `ym:s:deviceCategory=='mobile' AND ym:s:regionCity=='Москва'`.
- Название: `[Ретаргет] <кто> — <условие>`.
- Удаление сегмента ломает ретаргетинг Директа по нему — необратимая операция.

## ТЗ на JS-событие (для разработчика)

```
Задача: отправлять в Метрику событие «<имя цели>» при <точное условие: успешный ответ сервера на отправку формы заявки>.

Код (вставить в обработчик успешной отправки):
  ym(<COUNTER_ID>, 'reachGoal', '<goal_id_латиницей>');

Где: <страница/компонент>, все формы заявки (шапка, футер, попап, карточка).
Не отправлять: при открытии формы, при ошибке валидации, повторно при перезагрузке.
Проверка: открыть сайт с ?_ym_debug=1, отправить тестовую заявку — в консоли браузера видно reachGoal с id '<goal_id>'.
Цель в Метрике уже создана: ID <goal_metrika_id>, тип «JavaScript-событие», условие — id '<goal_id>'.
```

Идентификатор события — латиница, без пробелов, смысловой: `form_lead_sent`, `phone_click`, `cart_add`.
