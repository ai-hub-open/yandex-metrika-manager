# v1.1.3 — модель атрибуции названа точно

Обновление с v1.1.2.

**Что изменилось.** Агент задаёт модель атрибуции явно в каждом отчёте и подписывает число той
моделью, по которой Метрика его реально посчитала. Числа из разных моделей он не сравнивает и не
делит друг на друга. Если Метрика не приняла параметр, агент не делает вывод «этих данных нет», а
сверяет имя по справочнику; неполный ответ догружает или помечает.

**Что не изменилось.** Аудит и анализ только читают счётчик; цели и сегменты меняются только после
вашего «ОК».
