# v1.1.0 — установка плагином Claude Code

Обновление с v1.0.0.

Коротко: скилл Метрики теперь можно поставить в Claude Code плагином из маркетплейса ai-hub-open —
и новые версии будут приходить сами. Для Claude Desktop и claude.ai готовый архив теперь лежит в
релизах. Режимы аудита, анализа и управления не менялись.

## Что изменилось для вас

**1. Установка плагином в Claude Code.**
Сначала подключите коннектор Метрики — тот же адрес, что для Claude Desktop:

```
claude mcp add --scope user --transport http yandex-metrika "<адрес коннектора Метрики>"
```

Затем в сессии Claude Code:

```
/plugin marketplace add ai-hub-open/claude-plugins
/plugin install yandex-metrika-manager@ai-hub-open
```

Скилл вызывается как `/yandex-metrika-manager:yandex-metrika-manager` или словами: «проверь
Метрику». Чтобы обновления приходили сами: `/plugin` → **Marketplaces** → `ai-hub-open` →
**Enable auto-update**.

**2. Скилл сам скажет, что вышла новая версия.**
В начале разговора скилл сверяет свою версию с GitHub. Если есть новее — одним сообщением скажет,
что изменилось и как обновиться, и спросит, обновиться сейчас или продолжить. Без интернета проверка
молча пропускается. Сам себя скилл не обновляет — обновление ставите вы.

**3. Данные разборов не пропадут при обновлении.**
Папка `metrika/` создаётся там, где вы работаете, а не внутри скилла. Плагин при обновлении
заменяет свою папку целиком, поэтому держать там данные клиента нельзя — и скилл теперь это явно
соблюдает.

**4. Готовый архив для Claude Desktop — в релизах.**
`yandex-metrika-manager.zip` приложен к релизу.

## Обновление

- **Claude Code с плагином** — как выше; дальше `/plugin marketplace update ai-hub-open`.
- **Claude Desktop и claude.ai** — скачайте `yandex-metrika-manager.zip` из этого релиза и загрузите
  заново в Settings → Capabilities → Skills вместо старого.
- Если раньше скилл лежал папкой в `~/.claude/skills/yandex-metrika-manager`, удалите её — иначе в
  Claude Code скилл загрузится дважды.
