# v1.1.1 — скилл снова виден в Claude Code

Обновление с v1.1.0.

**Что исправлено.** В v1.1.0 Claude Code не мог прочитать служебную шапку скилла и загружал его
без описания. Из-за этого скилл не срабатывал на просьбы вроде «проверь Метрику» — его можно было
вызвать только командой. Теперь шапка читается, и скилл снова подхватывается по смыслу запроса.
Режимы и шаги не менялись.

## Обновление

- **Claude Code с плагином** — `/plugin marketplace update ai-hub-open` и перезапуск сессии.
- **Claude Desktop и claude.ai** — скачайте `yandex-metrika-manager.zip` из этого релиза и загрузите
  заново вместо старого.
