# Бриф субагента `direct-bridge` — Шаг 5 аудита

> **Это не отдельный скилл, а инструкция для форка.** Оркестратор `yandex-metrika-manager` передаёт тебе содержимое этого файла как задачу плюс аргументы.
>
> **Аргументы:** `$0` slug, `$1` counter_id, `$2` период, `$3` ID макро-целей, `$4` логины Директа (`chief_login`).

Ты — изолированный субагент Шага 5: смотришь на Директ **глазами Метрики**. Сохрани сырьё на диск, верни наверх **сводку не длиннее 20 строк**.

## Read-only — жёстко

Только тулы Метрики, оканчивающиеся на `report`, `report_bytime`, `goals_get`, `direct_clients_get`. **Никаких** записей в Метрику. **Тулы Директа не вызывай вообще** — даже если они видны в сессии: правка кампаний — задача `yandex-direct-audit`.

## Вход

Нет `$4` → `direct_clients_get({ counter_id: $1 })` → `chief_login`. Пусто → находка 🔴 «Директ не связан со счётчиком», верни её и закончи. Остальное — `metrika/$0/_state.json`, KPI оттуда же.

## Методология (прочитай)

`references/report-recipes.md` (R8–R11), `references/audit-checklist.md` → «Связка с Директом», `references/mcp-tools-map.md` → правило неймспейсов `ym:s:`/`ym:ad:`.

## Шаги

1. **R8** (клики, визиты, расход по кампаниям, `ym:ad:`) → `raw/05_ad.json`. Потеря клик→визит по каждой кампании.
2. **R9** (визиты, отказы, достижения макро-цели по кампаниям, `ym:s:`) → `raw/05_conv.json`.
3. Склейка → CPA по Метрике:
   `python -m scripts.metrika_table --input raw/05_conv.json --join raw/05_ad.json --join-key ym:s:lastsignDirectClickOrder --join-other-key ym:ad:directOrder --cost-col ym:ad:RUBAdCost --goal-col ym:s:goal<MACRO>reaches > 05_campaigns.csv`
   Названия кампаний в двух неймспейсах могут отличаться формой — проверь, сколько строк склеилось, несклеенное перечисли.
4. **R11** поиск vs сети.
5. **R10** фразы с визитами больше 50 и отказами больше 60% — список «кандидаты в минус» (рекомендация для `yandex-direct-audit`, не действие).
6. Модель атрибуции — последний значимый переход; если есть KPI и кампании явно верхневоронночные (охват, РСЯ) — повтори R9 с `attribution: "first"` и сравни.

## Выход

- `05_direct.md` — таблица кампаний: клики, визиты, потеря %, расход, достижения, CPA (Метрика), отказы; поиск vs сети; кандидаты в минус.
- `05_findings.json` — находки (`area`: «Директ»), `ready_to_use` — список фраз-кандидатов строкой.
- Наверх: ≤20 строк — общий расход и CPA, кампании с потерей больше 20%, кампании без конверсий, топ-3 по CPA, разница моделей атрибуции (словами), что передать в аудит Директа.
